# تطبيق «وين طلبي؟» - لزبائن شركة «وصّل»

تطبيق جوال تم تطويره لشركة **إيفان كود (Evan Code)** لمتابعة طلبات زبائن شركة «وصّل»، مع دعم العمل في وضع عدم الاتصال (Offline-First).

---

## 📱 المميزات الرئيسية

* **قائمة الطلبات:** عرض كافة الطلبات مع رقم الطلب، التاريخ، المبلغ بالريال اليمني، وشارة الحالة الملونة.
* **تحديث بالسحب (Pull-to-Refresh):** إمكانية تحديث البيانات يدوياً بسحب الشاشة.
* **فلترة الطلبات:** تصفية فورية وسلسة للطلبات حسب الحالة (الكل، جديد، في الطريق، تم التوصيل).
* **تفاصيل الطلب:**
  * بيانات العميل وعنوان التوصيل ورقم الهاتف.
  * قائمة الأصناف بالكميات والأسعار الإفرادية والإجمالية.
  * خط زمني عمودي تفاعلي لمراحل التوصيل (Timeline Tracker).
* **دعم انقطاع الإنترنت (Offline Caching):**
  * حفظ تلقائي للبيانات محلياً باستخدام `SharedPreferences`.
  * في حال انقطاع الاتصال، يسترجع التطبيق آخر نسخة محفوظة فوراً مع إظهار شريط تنبيه علوي يوضح توقيت آخر مزامنة.
* **تصميم عربي أصيل (RTL):** واجهة مستخدم نظيفة وعصرية متوافقة تماماً مع الاتجاه من اليمين لليسار.
* **حركات انتقال سلسة:** تنقلات أفقية ناعمة بنمط iOS.

---

## 🛠️ المعمارية والتقنيات (Architecture & Stack)

* **إطار العمل:** Flutter (Dart)
* **إدارة الحالة:** `Provider` (مع `ChangeNotifier`) لعزل منطق البيانات عن الواجهات.
* **التخزين المحلي:** `SharedPreferences` لتخزين الـ JSON محلياً والاعتماد عليه في وضع الأوفلاين.
* **التنسيق واللغة:** حزمة `intl` لتنسيق التواريخ والعملات.
